# 七海待办

Windows 11 本地待办应用，支持清单、优先级、四象限、月历、重复待办、子任务和专注计时。数据保存在电脑上，主题插画参考七海千秋。

## 从源码开始

安装 Node.js 后，在项目目录运行：

```powershell
npm ci
npm start
```

```powershell
npm test                 # 数据与日历测试
npm run test:desktop     # 桌面交互测试，使用独立测试数据
npm run package          # 生成 Windows x64 便携应用
npm run installer        # 生成可选择安装目录的 Windows 安装程序
```

打包输出到 `release/七海待办-win32-x64/`。首次打包需要下载 Electron；本地依赖、打包目录和测试缓存不纳入 Git。

可选开发工具：`scripts/make-icons.cjs` 需要 `sharp`；`scripts/preview-test.cjs` 需要 `playwright` 和它的 Chromium 浏览器，并需先启动 `npm run preview`。正常运行、测试和打包无需安装这两项。

## 使用便携版

双击 **七海待办.exe** 打开。适用于 Windows 11 x64，解压后即可运行，无需使用 CMD、安装 Node.js 或联网。程序位于 `release\七海待办-win32-x64` 文件夹中，请保留同文件夹内的配套文件。首次启动是空白清单。更新时先关闭旧版本窗口，再打开新版；原有待办数据会继续沿用。

## 使用安装版

双击 `release/七海待办-安装程序-1.1.0.exe`，按向导选择安装文件夹。安装后可从桌面或开始菜单打开「七海待办」，也可在 Windows「设置 → 应用 → 安装的应用」中卸载。安装包自带完整程序，安装过程无需联网；安装与卸载均保留已有待办数据。

## 记录和整理

- 「新建待办」或 Ctrl N：设置标题、备注、清单、优先级、截止日期、提醒时间、重复规则和子任务。
- 列表底部输入框：输入标题后按 Enter，快速添加。「今天」中创建的待办默认截止于今天。
- 点击圆圈完成待办；点击待办文字进行编辑。「已完成」中可以恢复待办。
- 「今天」包括今天到期和已逾期的任务；无日期任务在「全部待办」中。
- 「重要事项」包括重要任务和高优先级任务。优先级与重要／紧急属性可分别设置。
- 四象限：直接拖动待办到另一象限，会修改它的重要和紧急属性。左侧切换清单会保留当前的列表／四象限布局。
- 选择「手动排序」后，可在列表中拖动任务调整顺序。
- 「日历」在月历上显示每天到期的待办。点击日期查看当日详情；从这一天新建或快速添加，会自动填入该日期。可切换月份、选择年月或返回今天，点击月历上的待办可直接编辑。较多待办显示数量，点击日期查看全部；无日期任务仍在「全部待办」中。重复待办在完成后生成下一次，月底日期会适配当月天数。
- Ctrl K 搜索标题、备注、子任务；Ctrl Enter 保存编辑；Esc 关闭弹窗。

## 陪伴和专注

右侧可开始 15／25／45／60 分钟专注计时，支持暂停和重置。右上角展开按钮进入宽屏专注布局。设置中可切换深色模式或关闭插画。

**桌面提醒和专注提醒仅在程序运行时生效。** 最小化可以继续计时；关闭窗口会退出程序。首次启动便携版会创建「七海待办」开始菜单快捷方式，以支持 Windows 通知。提醒还受 Windows 通知设置和勿扰模式影响，不会为过去的日期补发提醒。系统通知不可用时，应用内仍会显示提醒。

## 本地数据

数据自动保存在 `%APPDATA%\ChiakiTodo\tasks.json`，不上传到服务器。`tasks.backup.json` 保存上一份可恢复快照。文件损坏时会尝试从这份备份恢复并保留损坏文件。

在「设置 → 导出备份」中另存一份 JSON；「导入备份」会校验文件、提示确认，并保存导入前副本。建议定期导出，尤其是在移动电脑前。设置中的「数据文件夹」可直接打开保存位置。

「载入示例待办」只会新增「示例」清单，用来体验界面；删除清单会保留其中待办，并移到另一份清单。要清除示例，可逐项删除示例待办，再删除清单。

## 源码运行

在项目目录执行 `npm install` 后，`npm start` 运行桌面版；`npm test` 运行数据逻辑测试；`npm run package` 生成 Windows 便携目录。`npm run preview` 只启动浏览器预览，预览数据与桌面版相互独立。

## 设计参考

功能参考 [苹果提醒事项](https://support.apple.com/guide/reminders/add-or-change-reminders-remndc729e28/mac) 的清单、优先级、截止日期和子任务。桌面封装使用 [Electron 的进程隔离建议](https://www.electronjs.org/docs/latest/tutorial/security/)，只加载随程序附带的本地资源。

七海千秋插画由内置图像工具生成，原始提示词保存在 `ASSET-PROMPT.md`。这是个人使用的非官方主题应用。
